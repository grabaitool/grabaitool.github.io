What is Muse Wonder?

Muse Wonder and Muse Wonder Full are Meta's newest frontier AI models, released on October 12, 2026 by Meta Superintelligence Labs as the company's most capable models to date. They are built specifically for personal and professional agentic work — multistep jobs that keep changing mid-run, like booking travel, untangling an insurance claim, or building an app. Two headline abilities drive that: Active Memory, which carries relevant context across conversations and recalls it when useful, and Active Focus, which keeps the agent trying alternative approaches when it gets blocked instead of stalling and asking you what to do.

Wonder is available now through the Meta Model API and inside Muse Code, Meta's AI coding tool, while Wonder Full is reserved for Muse Code subscribers. Meta says Wonder will soon power its Muse personal AI agent, starting with subscribers. Independent scoring from Artificial Analysis puts Wonder Full at 56 on its Intelligence Index — tying Claude Sonnet 5.5 and ahead of GPT-6 Astra — though the broader field of independent benchmarks is still early, and Meta's own comparison charts come from Meta itself.

Key Features

  • Active Memory: remembers relevant details across conversations and pulls them back when needed
  • Active Focus: keeps working toward hard goals, tries alternatives when blocked, and checks in before big actions
  • About a 1M-token context window with text, image, video, and audio input
  • API access via the Meta Model API (muse-wonder-1.0) and through OpenRouter
  • Strong reported performance on agent tasks, coding, law, finance, and health workflows

Pros

  • Frontier-class agentic performance at the same API list price as Claude Opus 5.5
  • Independent index scores put Wonder Full alongside the best models on the market
  • Two access paths: a pay-per-token API for builders and Muse Code for developers

Cons

  • Closed weights — no downloadable model, a break from Meta's earlier open Llama era
  • Benchmark leadership comes from Meta's own internal tests; independent verification is still thin
  • The most capable variant, Wonder Full, is locked behind Muse Code subscriptions at $50–$200/mo

Pricing

  • Model: Paid
  • API: $4 per 1M input / $20 per 1M output tokens; Muse app plans $20 or $100/mo; Muse Code $50 or $200/mo — check the official site for current pricing.
